# AGENTS.md

## Sobre o projeto

Este projeto (`tabnews-ai`) é uma reconstrução do **TabNews** — _"um lugar na internet para quem trabalha com tecnologia
e precisa consumir conteúdos com valor concreto"_.

O idioma principal da interface e dos conteúdos é **português do Brasil (`pt-BR`)**.

## Stack

- **Framework**: Next.js (App Router)
- **UI**: React
- **Linguagem**: TypeScript
- **Qualidade de código**: ESLint e Prettier
- **Gerenciador de pacotes**: `npm`

## Comandos

- `npm run dev` — inicia o servidor de desenvolvimento
- `npm run build` — gera o build de produção
- `npm run start` — inicia a aplicação em modo produção
- `npm run lint` — executa o ESLint
- `npm run lint:fix` — executa o ESLint aplicando correções automáticas
- `npm run format` — formata o projeto com Prettier
- `npm run format:check` — verifica a formatação com Prettier
